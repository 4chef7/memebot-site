Privacy Policy

MemeBot is a private, self-hosted tool used only by its operator to publish videos to the operator's own accounts. It has no other users and does not collect data from third parties.

YouTube API Services

MemeBot uses YouTube API Services to upload videos to the operator's own YouTube channel and to read basic information and statistics about the operator's own videos. Use of these services is subject to the YouTube Terms of Service and the Google Privacy Policy.

Data accessed and stored

  • An OAuth access token and refresh token for the operator's own Google account, stored only on the operator's own server.
  • IDs, titles and public statistics of videos uploaded by the tool, stored only on the operator's own server.

No data is sold, shared with or transferred to third parties. No data about other YouTube users is collected.

Revoking access and deleting data

Access can be revoked at any time in the Google security settings: https://security.google.com/settings/security/permissions. Stored tokens and data are deleted by removing them from the server; data obtained through the API is not kept longer than needed for the tool to work.
